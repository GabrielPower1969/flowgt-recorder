## 1. 名稱

**流錄**（英文名 FlowGT Recorder）

## 2. 一句話介紹

把螢幕、鏡頭和你的聲音錄成一個小巧的 MP4，只存在你的電腦上。

## 3. 詳細介紹

流錄把會議、面試或示範錄成一個 MP4：螢幕畫面、圓形小視窗裡的鏡頭畫面，加上麥克風的聲音。1080p 一小時約 400 MB，
存得下，也方便傳給別人。

- 按下開始，倒數 3 秒，倒數結束那一刻檔案就開始。
- 隨時暫停、繼續；按下停止得到一個完整檔案，不到一秒就存好。
- 用顯示卡硬體編碼（NVIDIA、Intel 或 Windows 內建編碼器），長時間錄製風扇也安靜。
- 相容模式（H.264）錄出的 MP4，所有電腦、手機和網頁都能直接播放。
- 錄到一半電腦當機，下次開啟會把已經錄下的部分找回來。
- 什麼都不離開你的電腦：不用註冊帳號，沒有遙測，沒有廣告。只有你自己登入 Google 後，錄影才可以另存一份到你自己的
  Google Drive 資料夾，不會傳到任何其他地方。

說明：Windows 上暫不錄製電腦聲音（系統音訊），只錄麥克風。支援 Windows 10（2004 版及以上）和 Windows 11。
介面提供簡體中文和英文。

## 4. 功能列表

- 螢幕＋鏡頭＋麥克風合成一個 MP4
- 圓形鏡頭小視窗，四個角落可選
- 整個螢幕或框選區域
- 1080p 每小時約 400 MB（HEVC）
- 相容模式（H.264）：到哪裡都能播
- 1080p／4K 畫質切換
- 倒數、暫停、繼續、停止
- NVIDIA、Intel 等顯示卡硬體編碼
- 意外中斷的錄影可以找回
- 全域快速鍵（Alt+Shift+R／P／S）
- 捲動截圖
- 可選上傳到你自己的 Google Drive
- 無需帳號，無遙測，無廣告
