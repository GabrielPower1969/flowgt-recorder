FlowGT. Recorder · 使用说明

面试录音插件，三分钟上手

把浏览器里的面试/会议录下来（对方声音 + 你的声音），文件只存在你自己的电脑里，不上传任何服务器。录完把文件发给 Gabriel，就能拿到完整的面试复盘报告。

1安装（只需一次，约 1 分钟）

  1. 把收到的 zip 解压到一个不会被删掉的位置（比如「文档」文件夹；不要放在临时下载目录里，删了插件就失效）。
  2. 打开 Chrome，地址栏输入 chrome://extensions 回车。
  3. 打开右上角的 开发者模式（Developer mode） 开关。
  4. 点左上角 加载已解压的扩展程序（Load unpacked） → 选择解压出来的 extension 文件夹。
  5. 点浏览器右上角的拼图图标 🧩，把 FlowGT Recorder 旁边的图钉点亮，固定到工具栏。

macOS 和 Windows 都可以用，步骤完全一样。

2首次设置：授权麦克风（最重要的一步！）

  1. 点一下工具栏上的 FlowGT 图标，弹出小面板。
  2. 如果看到黄色提示 “Microphone not enabled” → 点 Enable microphone → → 在浏览器弹窗里选 允许（Allow）。只需要做一次。
为什么重要：不授权麦克风也能录，但只会录到对方的声音，没有你自己的。 这种录音的文件名会带 _nomic 标记——看到它就说明你的声音没进去，回去把麦克风授权了再录。

如果浏览器没弹授权框，是系统层没放行，去打开：
· macOS：系统设置 → 隐私与安全性 → 麦克风 → 打开 Google Chrome
· Windows：设置 → 隐私 → 麦克风 → 允许桌面应用访问

3每次面试怎么用

  1. 用浏览器标签页入会（Google Meet / Zoom 网页版 / Teams 网页版）。收到 Zoom 链接时选「从浏览器加入 / Join from your browser」。
  2. 切到会议标签页，点 FlowGT 图标（或快捷键 ⌘⇧9 / Ctrl+Shift+9）。
  3. 在输入框填标签，格式：你的名字_公司_R轮次，例如 Iris_Datacom_R2。这会拼进文件名，方便归档。
  4. 点绿色的 Start recording。按钮变红、图标出现红色 REC 角标 = 正在录。
  5. 面试中可以随手关掉小面板，录音不会停；你也照常听得到对方说话。
  6. 面试结束：再点图标 → 红色的 Stop & save。文件自动保存到 下载/Downloads → flowgt-recordings 文件夹。

录音中（红色 + 计时）

就算面试页面被意外关掉，录音也会自动收尾保存，不会丢。

4录完 30 秒自检

  • 文件在 Downloads/flowgt-recordings/，名字类似 2026-09-07_1430_Iris_Datacom_R2.mp4。
  • 文件名不带 _nomic ✅（带了 = 你的声音没录进去）。
  • 双击播放，能听到对方和你自己两边的声音 ✅（.mp4 任何电脑双击就能播）。

5发给 Gabriel 拿复盘报告

把那个 .mp4 文件直接发给 Gabriel（微信发文件即可），并附一句：你的名字、公司、第几轮。 会收到一份完整的 HTML 复盘报告：8 个维度评分、关键时刻回放、口头禅统计、下一轮该怎么答的 60 秒范例。

6能录什么、不能录什么

场景支持？说明
Google Meet / Zoom 网页版 / Teams 网页版（浏览器标签页）✅主战场
Zoom / Teams 桌面客户端❌插件够不到浏览器外的声音。让 HR 发浏览器入会链接，或入会时选「从浏览器加入」
手机❌不支持
合规提醒：录音前请告知面试官（比如：“方便的话我想录音，仅用于自己复盘”）。 新西兰法律允许录制自己参与的对话，但主动告知永远是更职业、更稳妥的做法。录音只存你本机，不会上传。

7常见问题

  • 点了 Start 没反应 / 报错？ 确认当前是会议标签页（不能是 chrome:// 页面），刷新会议页面再试。
  • 面板关了是不是就停了？ 没有。录音一直在跑，直到你点 Stop & save 或会议页被关闭。看图标上的红色 REC 角标就知道在录。
  • 录音有回声？ 建议戴耳机面试，音质最好、也不会串音。
  • Chrome 提示「请移除此扩展」？ 开发者模式加载的扩展每次重启 Chrome 可能弹一次提示，点关闭即可，不影响使用。
