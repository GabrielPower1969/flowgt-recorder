## 外观「Studio」

深色底 `#0F1115`、浅色底 `#F6F5F2`；只有一个交互色（靛蓝）；红色只给「开始录制」「停止」「REC 圆点」；琥珀＝警告，绿＝正常。
界面字体 Inter，数字（计时、体积、码率、路径）用 JetBrains Mono。圆角 8 / 12 / 16。无渐变、无 emoji、线条图标、44px 触控目标。

## 规则

1. **App 使用 `design/tokens.css` 原文**，组件里不许出现写死的颜色；要改先改令牌。
2. 不加第二个交互色；红色是「正在录」的语义色，不做装饰。
3. 图标按钮都有 `aria-label`，输入框都有 `<label>`，全部可键盘操作。
4. 设计稿画板在设计模式里可继续改；改完把变化回写到 `tokens.css`。
