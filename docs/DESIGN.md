## 外观「Faceplate」（2026-11-11 起）

主窗口是一块开盘录音机的面板，造型参考 1965 年的 TG 60：米色机壳 `#ECE9DF` 上一块铝板 `#D5D7D8`（深色是石墨板 `#2A2C2E`），
两只大卷盘，一排米白方键，一个红点。只取造型语言，不用原机的商标、型号和刻字。

- **左盘**是磁盘还剩多少，**右盘**是这一段录了多少（一小时算一整盘）；录制时转，暂停时停。
- **监视窗**在正中，是会被录下来的画面：屏幕的静帧加摄像头小窗。磁带从左盘经过它走到右盘。
- **四个旋钮**：屏幕、摄像头在左，麦克风、电脑声音在右；设备在旋钮下面的下拉里选。
- **五个键**：历史｜暂停、录制、停止｜设置。红点键在正中。
- **纸卡**：成品、历史、设置是盖在两盘之间的米白卡片，下面那排键一直露着。
- **录制条**是缩小的同一块面板：两只小卷盘、暂停、读数窗（状态、计时、体积）、停止。

整个界面只有一处有颜色：红色，只表示「正在录」。操作用墨色（深色模式用近白），提醒用深底浅字的标签，不用琥珀和绿色。
界面字体 Inter，数字（计时、体积、路径）用 JetBrains Mono。圆角 2 / 3 / 5。无渐变、无 emoji。

面板按默认窗口 1180×760 画，窗口变小时整块等比缩小；最小窗口因此从 900×620 提到 1000×650。

**还没按新设计做的**（设计稿里有，代码里没有）：成品卡上逐项写「视频里有什么」（需要在录制结果里加字段）；
启动时提示「上次没录完」；摄像头没接上、麦克风没声音时录制条上的标签；录制条上的音量。

## 规则

1. **App 使用 `design/tokens.css` 原文**，组件里不许出现写死的颜色；要改先改令牌。
2. 不加交互色；红色是「正在录」的语义色，不做装饰，也不拿来写字。
3. 图标按钮都有 `aria-label`，输入框都有 `<label>`，全部可键盘操作。
4. 设计稿画板在设计模式里可继续改；改完把变化回写到 `tokens.css`。
