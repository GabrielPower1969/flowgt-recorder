## Result

2026-11-11, Windows 11 Pro build 26300, Intel integrated graphics, `npm run tauri dev`.

The first attempt did not record at all: the app froze when the screen picker opened. After that fix
(`shared/marker-window-deadlock`) the first recording on Windows was made at 01:13 local time:

```
> ffprobe … "2026-11-11 0113 trial-1.mp4"        (screen + microphone, 15 s)
codec_name=hevc  profile=Main  width=1920  height=1080  pix_fmt=yuv420p  r_frame_rate=30/1  nb_frames=452  duration=15.066667
codec_name=aac   profile=LC    sample_rate=48000  channels=2  duration=14.599646
format: duration=15.166667  size=1720847  bit_rate=907699
```

(Lines joined for space; values are as printed.) The command the app ran:

```
ffmpeg -hide_banner -loglevel warning -thread_queue_size 1024 -init_hw_device d3d11va -f lavfi
  -i ddagrab=output_idx=0:framerate=30:draw_mouse=1 -thread_queue_size 1024 -f dshow
  -i "audio=Microphone (Fifine Microphone)" -filter_complex [0:v]hwdownload,format=bgra,scale=1920:1080:flags=bicubic[vout];
  [1:a]aresample=48000:async=1,highpass=f=80,speechnorm=…,alimiter=…[aout] -map [vout] -map [aout]
  -c:v hevc_qsv -preset veryfast -tag:v hvc1 -b:v 793k -maxrate 1190k -bufsize 1586k -g 60 -pix_fmt yuv420p
  -r 30 -fps_mode cfr -c:a aac -b:a 96k -ar 48000 -ac 2 -movflags +frag_keyframe+empty_moov+default_base_moof
  -frag_duration 2000000 -progress pipe:1 -nostats -y …\.flowgt-recorder\<session>\seg-000.mp4
```

The two-minute run with the camera on and one pause (`win-verify`, 01:32):

```
> ffprobe -v error -show_entries format=duration,size,bit_rate:stream=codec_name,width,height,avg_frame_rate -of default=nw=1 "2026-11-11 0132 win-verify.mp4"
codec_name=hevc
width=1920
height=1080
avg_frame_rate=4797/160
codec_name=aac
avg_frame_rate=0/0
duration=160.100000
size=17897434
bit_rate=894312
```

Size and frame rate are right (384 MB/h, 29.98 fps), pause and resume produce two segments joined into one
file, and the session folder is removed. **The audio is wrong**: 152.5 s against 160.0 s of video, with a 7.7 s
hole at the pause. That and three more defects are in `docs/tasks/W-4.md`; all four are fixed there and the
run was repeated (`win-verify-2`: video 163.7 s, audio 163.7 s, no hole).

Numbers: `docs/BENCH.md` → Windows. Checklist: `docs/WINDOWS-VERIFY.md`. Screenshots (git-ignored):
`tests/out/win-night/screens/`. Recordings: the `Videos/FlowGT Recorder` folder of the test machine.

## Not verified

- No person watched or listened to any file. Checks were ffprobe, a full decode, frame grabs and audio level.
- Sound and picture in step with a real signal (clap, beep): no loopback device, and no sound was played at night.
- The tray icon while recording.
- Non-ASCII device names (none on this machine).
- System audio (no loopback device; W-5).
- Whether "Same as system" names the device Windows really uses as its default.
